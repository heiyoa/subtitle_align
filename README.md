# 精准对齐字幕工具

英文目录名：`subtitle_align`

## 概述

`subtitle_align` 是一个独立的字幕生成与时间对齐模块，用于在音视频处理链路中提供稳定的基础字幕能力。

项目重点不在“快速出字幕”，而在于保证字幕结果具备可复查性、可回执性和可作为后续流程输入的稳定性。

## 场景示例

以一段口播视频为例，后续可能还需要执行：

- 精剪
- 节奏调整
- 草稿装配
- 导出

在这些步骤开始之前，需要先得到一份时间基本准确、文本可复查的字幕结果。`subtitle_align` 负责的正是这一层工作。

## 设计目标

- 将字幕层从复杂视频流程中独立出来
- 为后续流程提供稳定输入
- 记录运行中间结果和回执，便于排查
- 在有限环境下保持可执行性

## 模块划分

### `subtitle_align/`
负责核心字幕生成、对齐、后处理与结果输出。

### `tests/`
负责基础行为验证，保证关键规则能够稳定复现。

### `CODE_INDEX.md`
负责快速定位模块与关键能力点，便于交接与维护。

## 工作流实现

字幕链路的实现方式如下：

1. 输入音频或视频文件
2. 生成转写结果与词级时间信息
3. 对结果做对齐与后处理
4. 输出字幕文件
5. 同时输出 `transcript.json` 和 `run_receipt.json`

通过保留中间结果和运行回执，可以将“生成结果”和“执行过程”同时记录下来，而不是只保留最终字幕文件。

## 容灾与稳定性设计

### 1. 中间结果保留
保留 `transcript.json`，便于后续补处理和人工检查。

### 2. 运行回执独立输出
保留 `run_receipt.json`，便于判断本次执行是否存在降级或异常。

### 3. OCR 校验可选
将 OCR 校验设计为附加能力，而非主流程硬依赖，避免附加模块影响核心链路。

### 4. 底层模块独立
字幕层单独拆分，避免问题扩散到更上游的视频工作流中。
